- 正式設定的 Google Sheet 先前只進行唯讀 API 檢查；當時解析停在 C9，因 `$q_2_2$` 仍位於題目格文字。教師須先依 [README](../README.md) 備份並把六個 q 鍵移到各自題目格**備註**、格內保留純題目文字，再執行 `node --env-file=.env scripts/check-sheet-readonly.mjs`。本輪未修改真實工作表，也未驗證真實答案寫入權限。
