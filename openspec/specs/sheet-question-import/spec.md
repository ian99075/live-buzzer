# sheet-question-import Specification

## Purpose

讓教師從指定 Google Sheet 題目格備註中的佔位符建立單題與題組，並在課堂進行中安全地增量重新匯入，同時維持題號對應及既有搶答資料。

## Requirements

### Requirement: 從題目格匯入單題與小題
系統 SHALL 僅由已登入教師手動觸發匯入，從後端設定的 Google Sheet ID 與分頁讀取題目。題目格備註中的 `$q_N$` 代表 Case N 單題，`$q_N_M$` 代表 Case N 的第 M 小題；同格非空純文字為題目內容。題組標題 SHALL 預設為「題組 N」，標題本身不得另接受搶答，整個題組 SHALL 是一個共用倒數與提交的搶答單位。匯入 SHALL 不修改 Sheet。

#### Scenario: 匯入目前工作表
- **WHEN** 工作表六個題目格的備註分別含 `$q_1_1$`、`$q_1_2$`、`$q_2_1$`、`$q_2_2$`、`$q_3$`、`$q_4$`，格內各有純題目文字
- **THEN** 教師清單建立 Case 1 與 2 各一個含兩小題的草稿題組及 Case 3、4 單題；題組各只有一份草稿狀態及共用秒數，師生畫面只顯示題目文字，Sheet 本身不被匯入操作修改

#### Scenario: 題號不依儲存格位置推算
- **WHEN** 含 `$q_4$` 備註及其題目文字的儲存格移到同分頁另一格
- **THEN** 匯入的題號仍為 Case 4，不由列、欄或匯入順序改號

### Requirement: 題目與答案佔位符配對驗證
系統 SHALL 在改變課堂前驗證每個題目備註佔位符與同分頁唯一的同鍵答案佔位符配對；答案鍵可位於答案格文字或備註。題目鍵、答案鍵各自不得重複，同一 Case 不得同時出現單題與小題形式。題目格內若仍留有 `$q_...$`，SHALL 提示教師先手動移至同格備註。無效資料 SHALL 使整次匯入失敗，不新增或修改任何題目。

#### Scenario: 缺少答案位置
- **WHEN** 題目格備註有 `$q_1_2$`，但找不到 `$a_1_2$` 文字或備註
- **THEN** 匯入回報可辨識的格式錯誤，原本課堂題目、秒數、狀態及回答皆不變

#### Scenario: 重複或混用鍵
- **WHEN** 兩格備註都含 `$q_1$`，或備註同時含 `$q_1$` 與 `$q_1_1$`
- **THEN** 匯入拒絕整份資料，不依儲存格先後猜測哪一題有效

#### Scenario: 題目內容不合法
- **WHEN** 題目格備註只有 `$q_2$` 而格內無文字，或格內去除前後空白後超過 2000 字元
- **THEN** 匯入拒絕且不改變課堂資料

#### Scenario: 題目文字仍殘留佔位符
- **WHEN** 教師尚未將 C5 文字末尾的 `$q_1_1$` 移入 C5 備註，就按匯入題目
- **THEN** 系統指出 C5 須先在 Sheet 手動移動標記，拒絕本次匯入且不修改 Sheet 或課堂

### Requirement: 增量重新匯入保留課堂
系統 SHALL 以來源佔位符鍵識別既有單題／小題；重匯時僅新增新單題或尚為 draft 題組的小題，既有草稿內容可更新但保留教師設定的單題／題組秒數與 ID。題組首次開始後 SHALL 鎖定小題集合；若 Sheet 出現該題組新 `$q_N_M$`，SHALL 回傳 409，整次匯入不新增或更新**任何**題目，不留下半套課堂。open、paused、settled 單題／題組的內容、ID、計時、完整回答、順位與失格紀錄 SHALL 保留。來源暫時缺少的既有題目 SHALL 不因重匯自動刪除，缺鍵只回報警示。

#### Scenario: 草稿題組加入新小題
- **WHEN** Case 1 題組仍為 draft，教師在 Sheet 加入 `$q_1_3$` 與 `$a_1_3$` 後再次匯入
- **THEN** 1-3 以原題號加入同一草稿題組；共用秒數及既有小題 ID 不變

#### Scenario: 已開始題組新增小題被整批拒絕
- **WHEN** Case 1 題組已開始且已有完整提交，教師在 Sheet 加入 `$q_1_3$`、`$a_1_3$`，同時修改另一草稿單題文字後再次匯入
- **THEN** 回傳 409，1-3 不加入、另一草稿單題文字也不更新，Case 1 的成員、倒數、回答與順位不變

#### Scenario: 草稿文字更新而秒數保留
- **WHEN** 教師已將草稿 Case 1 題組設為 45 秒，後來修改帶有 `$q_1_2$` 備註的題目格文字並重新匯入
- **THEN** 1-2 的內容更新、題組共用秒數仍為 45、小題與題組 ID 不變

#### Scenario: 進行中題組的來源文字改變
- **WHEN** 教師在 Case 1 題組開始後修改 Sheet 的 1-1 題目文字並重新匯入，但沒有新增小題
- **THEN** 本堂課 Case 1 的小題文字與完整回答保持原樣，不中途替換題幹

#### Scenario: 來源鍵暫時消失
- **WHEN** 已匯入的 Case 3 在 Sheet 的備註暫時找不到 `$q_3$`，教師重新匯入
- **THEN** 本堂課 Case 3 不被自動刪除，系統回報該鍵未在此次來源中找到

### Requirement: 題目匯入 API 與失敗回復
系統 SHALL 提供 `POST /api/teacher/questions/import-google-sheet`，僅接受已登入教師且無任意 Sheet ID、分頁或範圍輸入。成功 SHALL 回傳新增、更新與保留的題目數及來源警示；讀取、權限、配額或逾時失敗 SHALL 不清空課堂，不洩漏憑證或遠端敏感錯誤。

#### Scenario: 未登入或指定任意 Sheet
- **WHEN** 未登入者呼叫匯入，或登入教師在請求中指定另一個 Sheet ID
- **THEN** 分別回傳 401 或 400，後端僅使用自身設定的目標表格

#### Scenario: 遠端讀取失敗
- **WHEN** Google API 無法讀取、憑證無效或請求逾時
- **THEN** 匯入回報失敗，原有題目、回答與教師登入保持不變

#### Scenario: 服務重啟後需重新匯入
- **WHEN** Node 服務重啟，教師重新登入
- **THEN** 課堂題目仍為空，直到教師再次手動匯入；Sheet 中既有答案不被自動清空
